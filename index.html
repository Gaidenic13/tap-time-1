MVP path

One entrance.
One team. Four weeks.

Validate the behavior before investing in custom hardware. Start with an NFC tag, this enclosure, and a small web flow.

Read the full proposal ↗
  1. Week 1Print & program

    Print the enclosure and write the pilot URL to the NFC tag.

  2. Week 2Team test

    Enroll 5–10 employees and observe the entry flow.

  3. Weeks 3–4Measure & learn

    Track successful taps, corrections, and payroll usefulness.

MVP honesty

A passive NFC tap proves that a phone reached the tag. It does not, by itself, prove who held the phone. Production should add authenticated employee accounts, rotating signed links, audit logs, and a dedicated reader where stronger assurance is required.
